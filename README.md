# Excel Data Analyzer

This application allows users to upload an Excel file, select a field to analyze, and generate a frequency table, bar chart, and pie chart. The results are saved in a downloadable Excel file.

## Features

- Upload Excel files (.xlsx or .xls)
- Select a field to analyze
- Generate frequency table with counts and percentages
- Create bar chart visualization
- Create pie chart visualization
- Download results as a single Excel file
